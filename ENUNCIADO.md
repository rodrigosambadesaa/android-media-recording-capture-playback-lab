# Enunciado / material de partida — Grabación, captura y reproducción multimedia

Fuente: bloque histórico de **Grabación** de Programación Multimedia y Dispositivos Móviles.

Construir una aplicación Android que permita practicar la adquisición y reproducción de contenido multimedia:

- grabar audio y reproducir posteriormente la grabación;
- capturar una fotografía mediante la aplicación de cámara;
- capturar un vídeo;
- seleccionar contenido multimedia existente;
- reproducir vídeo desde la aplicación mediante controles de reproducción.

La aplicación debe solicitar únicamente los permisos necesarios para cada función. La versión moderna sustituye almacenamiento externo general y APIs antiguas de resultados por almacenamiento propio de la app, `FileProvider` y Activity Result APIs.

No existe una base de datos asociada.
